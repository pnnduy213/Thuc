# BÀI THỰC HÀNH 05 - NHÓM 02
## 1. Mô tả nội dung thực hành
Bài thực hành thực hiện về chủ đề **"Ứng dụng công nghệ số trong học tập"**. Nội dung trình bày về vai trò, lợi ích của việc áp dụng công nghệ số, các nền tảng trực tuyến và trí tuệ nhân tạo (AI) giúp tối ưu hóa quá trình học tập, cá nhân hóa lộ trình và gia tăng sự tương tác, kết nối giữa học sinh và giáo viên. Các sản phẩm được hoàn thiện dưới dạng văn bản tổng hợp, hình ảnh infographic, video ngắn truyền thông và trang web hiển thị HTML.
## 2. Danh sách file
* **`1.1 ,1.2_TH5_nhom2.pdf`**: File văn bản tổng hợp nội dung thực hành về ứng dụng công nghệ số trong học tập.
* **`2.1 thực hành 05 nhóm 2.jpg`**: File hình ảnh Infographic truyền thông tóm tắt các lợi ích chính.
* **`2.2 thực hành 05 nhóm 2.mp4`**: File video minh họa nội dung ứng dụng công nghệ số trong học tập.
* **`3.1 thực hành 05 nhóm 2.html`**: File mã nguồn HTML hiển thị tích hợp infographic và video.
* **`cmt_lsusuanhom2th5.pdf`**: File ghi nhận lịch sử chỉnh sửa tài liệu và các nhận xét, góp ý của nhóm.
